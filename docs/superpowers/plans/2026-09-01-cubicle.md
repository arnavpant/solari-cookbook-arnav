# cubicle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a runnable computer-use benchmark that scores AI agents on ten real bookkeeping tasks in GnuCash on a Solari cloud desktop, graded by SQL over the app's own database.

**Architecture:** A synchronous Python harness on the developer's machine drives a remote Solari desktop. GnuCash is installed once and snapshotted; each task reverts to that snapshot, writes its own seed book, runs an agent loop of `screenshot -> act` for a capped number of steps, then downloads the book and grades it with `sqlite3`. Agents implement one method (`act`). A scripted oracle proves every task is solvable.

**Tech Stack:** Python 3.11+, `solari-desktop==0.2.0` (async `DesktopClient` driven from one owned event loop), `piecash` (seed generation), stdlib `sqlite3` (grading), `pytest`, `google-genai`, `openai` SDK pointed at DeepSeek.

**Spec:** `docs/superpowers/specs/2026-09-01-cubicle-design.md`

## Global Constraints

- Python 3.11+ (uses `X | None` syntax in dataclasses).
- **`SyncDesktopClient` is only half sync.** Verified in the SDK source: it wraps the
  *client* calls (`create`/`get`/`destroy`/`pause`/`resume`/`connect`) on a private event
  loop, but the `Desktop` handle it returns is **async**. Its own docstring says "the
  returned Desktop handle is async, so prefer DesktopClient when driving the control
  channel." Everything the benchmark uses — `screenshot`, `mouse.*`, `keyboard.*`,
  `fs.*`, `exec`, `snapshot`, `revert` — is a coroutine.
  **Therefore:** the harness owns one `asyncio` event loop, uses the async `DesktopClient`,
  and `CubicleDesktop` is a sync facade that calls `loop.run_until_complete()` on every
  Desktop coroutine. `Agent.act()` stays **synchronous** — that is the whole point of the
  pluggable interface and must not become async.
- **Solari Starter plan: max 2 concurrent desktops/sandboxes.** Worker pool hard-capped at 2.
- **`429 ConcurrencyLimitExceeded` is NEVER retryable.** A slot frees only when you pause or kill a session. Never back off and retry into it.
- **A `200` from `exec` means only the HTTP call worked.** Always check `ExecResult.exitCode`.
- **`GET /sessions/:id` always returns 404.** Never poll session status; use `health()`.
- **Never parse Solari error prose.** Branch on HTTP status or `code`.
- Desktop machine size is always `cpu=1, mem_mb=2048`, resolution `1280x720`.
- The agent action space is **pixels, mouse and keyboard only**. `clipboard`, `exec`, `fs`, `run_code` and `process` are harness-only and must never be reachable from an `Agent`.
- All ten task prompts carry their own data inline. GnuCash is the only thing on screen.
- Money is compared as exact integers via `value_num`/`value_denom`. Never floats.
- `SOLARI_API_KEY`, `GEMINI_API_KEY`, `DEEPSEEK_API_KEY` come from `.env` / environment. **Never commit a key, never print one.**

```python
# scripts/probe.py
"""One-shot probe. Answers the three open questions in the spec, prints findings, exits."""
import os, sys, time
from solari_desktop import SyncDesktopClient

BASE_URL = "https://api.getsolari.com"

def main() -> None:
    client = SyncDesktopClient(api_key=os.environ["SOLARI_API_KEY"], base_url=BASE_URL)
    d = client.create(template="default", cpu=1, mem_mb=2048,
                      resolution="1280x720", timeout_ms=15 * 60_000)
    print("session:", d.sessionId)
    print("watch  :", getattr(d, "streamUrl", "<none>"))
    try:
        d.connect()
        for _ in range(60):
            if getattr(d.health(), "ready", False):
                break
            time.sleep(1)

        # Q1: does gnucash install, and what version?
        r = d.pkg.install("apt", ["gnucash"])
        print("Q1 pkg.install ->", r)
        v = d.exec("gnucash", args=["--version"], timeout_ms=120_000)
        print("Q1 version exit:", v.exitCode, "out:", (v.stdout or "").strip()[:200])

        # Q2: does revert restore a dirtied filesystem?
        d.fs.write("/root/canary.txt", "before-snapshot\n")
        snap = d.snapshot("probe-snap")
        print("Q2 snapshot id:", snap)
        d.fs.write("/root/canary.txt", "AFTER-snapshot\n")
        d.revert(snap)
        time.sleep(3)
        d.reconnect()
        after = d.fs.read_text("/root/canary.txt")
        print("Q2 canary after revert:", repr(after),
              "-> PASS" if after.strip() == "before-snapshot" else "-> FAIL")

        # Q3: what lifecycle shapes does create() accept?
        for shape in ({"onIdle": "pause"}, {"on_idle": "pause"},
                      {"idle": {"action": "pause"}}, {"action": "pause"}):
            try:
                probe = client.create(template="default", cpu=1, mem_mb=2048,
                                      lifecycle=shape, timeout_ms=60_000)
                print("Q3 ACCEPTED:", shape)
                client.destroy(probe.sessionId)
                break
            except Exception as e:  # noqa: BLE001 - probing on purpose
                print("Q3 rejected:", shape, type(e).__name__, str(e)[:160])
    finally:
        d.close()
        client.destroy(d.sessionId)

if __name__ == "__main__":
    sys.exit(main())
```

```python
# cubicle/types.py
from __future__ import annotations
from dataclasses import dataclass
from typing import Callable, Literal, Protocol

ActionKind = Literal["click", "double_click", "type", "key", "scroll", "drag", "done"]
ScrollDir = Literal["up", "down", "left", "right"]
Outcome = Literal["pass", "wrong_state", "timeout", "crash", "corrupt"]
Tier = Literal["easy", "medium", "hard"]

@dataclass(frozen=True)
class Observation:
    screenshot_png: bytes
    width: int
    height: int
    step: int
    max_steps: int
    task_prompt: str

@dataclass(frozen=True)
class Action:
    kind: ActionKind
    x: int | None = None
    y: int | None = None
    text: str | None = None
    scroll_direction: ScrollDir | None = None
    scroll_amount: int | None = None
    to_x: int | None = None
    to_y: int | None = None

    def __post_init__(self) -> None:
        if self.kind in ("click", "double_click", "scroll", "drag"):
            if self.x is None or self.y is None:
                raise ValueError(f"{self.kind} requires x and y")
        if self.kind in ("type", "key") and not self.text:
            raise ValueError(f"{self.kind} requires text")
        if self.kind == "drag" and (self.to_x is None or self.to_y is None):
            raise ValueError("drag requires to_x and to_y")

@dataclass(frozen=True)
class Verdict:
    passed: bool
    reason: str = ""

    def __post_init__(self) -> None:
        if not self.passed and not self.reason:
            raise ValueError("a failing Verdict must carry a reason")

@dataclass
class TaskResult:
    task_id: str
    agent: str
    outcome: Outcome
    reason: str
    steps_used: int
    max_steps: int
    model_seconds: float
    desktop_seconds: float
    unparseable_responses: int
    session_id: str

@dataclass(frozen=True)
class Task:
    task_id: str
    tier: Tier
    max_steps: int
    prompt: str
    seed: Callable[[], bytes]
    grade: Callable[[str], Verdict]
    oracle: Callable[[object], None]
```

```python
# cubicle/fixtures/build_seed.py
"""Generates every seed book programmatically so they are reproducible and diffable."""
from __future__ import annotations
import datetime as dt, functools, os, tempfile
from decimal import Decimal
import piecash
from piecash import Account, Commodity, Transaction, Split

BASE_ACCOUNTS = [
    ("Checking", "BANK", "Assets"), ("Savings", "BANK", "Assets"),
    ("Office Supplies", "EXPENSE", "Expenses"), ("Utilities", "EXPENSE", "Expenses"),
    ("Electric", "EXPENSE", "Expenses:Utilities"), ("Water", "EXPENSE", "Expenses:Utilities"),
    ("Technology", "EXPENSE", "Expenses"), ("Misc", "EXPENSE", "Expenses"),
    ("Consulting", "INCOME", "Income"),
]

# 12 entries: 6 in March 2026 (targets for t06), 6 outside it (traps for t06).
BASE_TXNS = [
    ("2026-02-03", "Feb rent share", "Office Supplies", "120.00"),
    ("2026-02-11", "Coffee supplies", "Office Supplies", "18.75"),
    ("2026-02-24", "Domain renewal", "Technology", "22.00"),
    ("2026-03-02", "March paper order", "Office Supplies", "64.00"),
    ("2026-03-06", "Electric bill", "Electric", "88.40"),
    ("2026-03-11", "Water bill", "Water", "31.20"),
    ("2026-03-17", "Laptop stand", "Technology", "51.25"),
    ("2026-03-23", "Stationery", "Office Supplies", "12.99"),
    ("2026-03-29", "Cloud hosting", "Technology", "40.00"),
    ("2026-04-04", "April paper order", "Office Supplies", "58.00"),
    ("2026-04-09", "Postage", "Misc", "9.10"),
    ("2026-04-18", "Printer toner", "Office Supplies", "76.30"),
]

def _find(book, full_name: str) -> Account:
    node = book.root_account
    for part in full_name.split(":"):
        node = next(a for a in node.children if a.name == part)
    return node

def _add_txn(book, usd, when: str, desc: str, expense_full: str, amount: str) -> None:
    amt = Decimal(amount)
    Transaction(
        currency=usd, description=desc,
        post_date=dt.date.fromisoformat(when),
        splits=[Split(account=_find(book, expense_full), value=amt),
                Split(account=_find(book, "Assets:Checking"), value=-amt)],
    )

def build_base(path: str, variant: str = "base") -> None:
    if os.path.exists(path):
        os.remove(path)
    book = piecash.create_book(path, overwrite=True, currency="USD", keep_foreign_keys=False)
    usd = book.commodities.get(mnemonic="USD")
    for top in ("Assets", "Expenses", "Income"):
        Account(name=top, type="ASSET" if top == "Assets" else
                ("EXPENSE" if top == "Expenses" else "INCOME"),
                commodity=usd, parent=book.root_account)
    book.save()
    for name, atype, parent in BASE_ACCOUNTS:
        Account(name=name, type=atype, commodity=usd, parent=_find(book, parent))
    book.save()

    for when, desc, exp, amt in BASE_TXNS:
        _add_txn(book, usd, when, desc, f"Expenses:{'Utilities:' if exp in ('Electric','Water') else ''}{exp}", amt)
    book.save()

    if variant == "t05":
        _add_txn(book, usd, "2026-03-19", "Invoice 1041", "Expenses:Technology", "250.00")
    elif variant == "t07":
        Account(name="Software Subscriptions", type="EXPENSE", commodity=usd,
                parent=_find(book, "Expenses"))
    elif variant == "t09":
        # Statement line 'Bank fee' is deliberately absent; the agent must add it.
        pass
    elif variant == "t10":
        _add_txn(book, usd, "2026-03-25", "Adjustment A", "Expenses:Misc", "15.00")
        _add_txn(book, usd, "2026-03-26", "Adjustment B", "Expenses:Misc", "25.00")
    book.save()
    book.close()

@functools.lru_cache(maxsize=None)
def seed_bytes(variant: str = "base") -> bytes:
    fd, p = tempfile.mkstemp(suffix=".gnucash"); os.close(fd)
    try:
        build_base(p, variant)
        with open(p, "rb") as f:
            return f.read()
    finally:
        os.remove(p)
```

```python
# cubicle/grading.py
"""Every grader goes through here. Plain sqlite3 only - no ORM, no model, no judge."""
from __future__ import annotations
import os, sqlite3, tempfile
from decimal import Decimal
from cubicle.types import Verdict

def write_temp_book(data: bytes) -> str:
    fd, path = tempfile.mkstemp(suffix=".gnucash"); os.close(fd)
    with open(path, "wb") as f:
        f.write(data)
    return path

def open_book(path: str) -> sqlite3.Connection:
    con = sqlite3.connect(path)
    con.row_factory = sqlite3.Row
    return con

def money(num: int, denom: int) -> str:
    """Exact decimal string. Never returns a float."""
    return str((Decimal(num) / Decimal(denom)).quantize(Decimal("0.01")))

def account_by_name(con: sqlite3.Connection, name: str):
    return con.execute("SELECT * FROM accounts WHERE name = ?", (name,)).fetchone()

def txn_by_description(con: sqlite3.Connection, desc: str):
    return con.execute("SELECT * FROM transactions WHERE description = ?", (desc,)).fetchone()

def txns_by_description(con: sqlite3.Connection, desc: str):
    return con.execute("SELECT * FROM transactions WHERE description = ?", (desc,)).fetchall()

def splits_for(con: sqlite3.Connection, tx_guid: str):
    return con.execute("SELECT * FROM splits WHERE tx_guid = ?", (tx_guid,)).fetchall()

def check_integrity(con: sqlite3.Connection) -> Verdict:
    """Applied to EVERY task. Splits must sum to zero for every transaction."""
    rows = con.execute(
        "SELECT tx_guid, SUM(CAST(value_num AS REAL) / value_denom) AS total "
        "FROM splits GROUP BY tx_guid"
    ).fetchall()
    for r in rows:
        if abs(r["total"]) > 1e-9:
            return Verdict(False, f"transaction {r['tx_guid']} does not balance (sum={r['total']})")
    return Verdict(True)
```

```python
# cubicle/desktop.py
"""Wraps a Solari Desktop. The agent never touches this - the harness does."""
from __future__ import annotations
import time
from cubicle.types import Action

BOOK_PATH = "/root/book.gnucash"
BOOK_COPY = "/root/book.copy.gnucash"

class CubicleDesktop:
    def __init__(self, desktop, snapshot_id: str) -> None:
        self.d = desktop
        self.snapshot_id = snapshot_id

    def _exec(self, cmd: str, args: list[str] | None = None, timeout_ms: int = 60_000):
        # A 200 only means the HTTP call worked. The real result is exitCode.
        r = self.d.exec(cmd, args=args, timeout_ms=timeout_ms)
        if getattr(r, "exitCode", 0) != 0:
            raise RuntimeError(f"{cmd} exit {r.exitCode}: {getattr(r, 'stderr', '')[:300]}")
        return r

    def start_task(self, seed: bytes) -> None:
        self.d.revert(self.snapshot_id)
        time.sleep(2)
        self.d.reconnect()
        self.d.fs.write(BOOK_PATH, seed)
        self.d.open("gnucash", [BOOK_PATH])
        self.wait_for_gnucash_ready()

    def wait_for_gnucash_ready(self, timeout_seconds: int = 90, poll_seconds: float = 1.0) -> None:
        """health().ready means X11 is up, NOT that GnuCash has finished drawing."""
        deadline = time.time() + timeout_seconds
        previous: bytes | None = None
        seen_process = False
        while time.time() < deadline:
            if not seen_process:
                names = " ".join(getattr(p, "name", "") for p in self.d.process.list())
                seen_process = "gnucash" in names
            if seen_process:
                current = self.d.screenshot(format="png")
                if previous is not None and current == previous:
                    return
                previous = current
            if poll_seconds:
                time.sleep(poll_seconds)
        raise TimeoutError("GnuCash did not settle within the readiness timeout")

    def screenshot(self) -> bytes:
        return self.d.screenshot(format="png")

    def apply(self, action: Action) -> None:
        k = action.kind
        if k == "done":
            return
        if k == "click":
            self.d.mouse.click(action.x, action.y, humanize=True)
        elif k == "double_click":
            self.d.mouse.double_click(action.x, action.y)
        elif k == "type":
            self.d.keyboard.type(action.text)
        elif k == "key":
            self.d.keyboard.press(action.text)
        elif k == "scroll":
            self.d.mouse.scroll(action.x, action.y,
                                direction=action.scroll_direction or "down",
                                amount=action.scroll_amount or 3)
        elif k == "drag":
            self.d.mouse.drag(action.x, action.y, to_x=action.to_x, to_y=action.to_y)
        else:
            raise ValueError(f"unknown action kind {k}")

    def read_book(self) -> bytes:
        """GnuCash may hold a lock; copy inside the VM first, then read the copy."""
        self._exec("cp", args=[BOOK_PATH, BOOK_COPY])
        return self.d.fs.read(BOOK_COPY)
```

```python
# cubicle/harness.py
from __future__ import annotations
import time
from pathlib import Path
from cubicle.desktop import CubicleDesktop
from cubicle.grading import check_integrity, open_book, write_temp_book
from cubicle.types import Observation, TaskResult, Task, Verdict

class UnparseableResponse(Exception):
    """Raised by an agent when the model's reply is not a valid Action."""

def run_task(cd: CubicleDesktop, agent, task: Task,
             trace_dir: Path | None = None) -> TaskResult:
    agent.reset()
    steps = unparseable = 0
    model_s = desktop_s = 0.0

    def result(outcome: str, reason: str) -> TaskResult:
        return TaskResult(task_id=task.task_id, agent=agent.name, outcome=outcome,
                          reason=reason, steps_used=steps, max_steps=task.max_steps,
                          model_seconds=round(model_s, 2),
                          desktop_seconds=round(desktop_s, 2),
                          unparseable_responses=unparseable,
                          session_id=getattr(cd.d, "sessionId", "unknown"))

    try:
        t0 = time.monotonic(); cd.start_task(task.seed()); desktop_s += time.monotonic() - t0

        for step in range(task.max_steps):
            t0 = time.monotonic(); shot = cd.screenshot(); desktop_s += time.monotonic() - t0
            if trace_dir:
                trace_dir.mkdir(parents=True, exist_ok=True)
                (trace_dir / f"step-{step:03d}.png").write_bytes(shot)

            obs = Observation(screenshot_png=shot, width=1280, height=720,
                              step=step, max_steps=task.max_steps, task_prompt=task.prompt)
            t0 = time.monotonic()
            try:
                action = agent.act(obs)
            except UnparseableResponse:
                unparseable += 1
                steps += 1
                model_s += time.monotonic() - t0
                continue
            model_s += time.monotonic() - t0

            steps += 1
            if action.kind == "done":
                break
            t0 = time.monotonic(); cd.apply(action); desktop_s += time.monotonic() - t0
        else:
            # Step cap reached without the agent calling done.
            book = cd.read_book()
            v = task.grade(write_temp_book(book))
            return result("pass", "") if v.passed else result("timeout", v.reason or "step cap reached")

        t0 = time.monotonic(); book = cd.read_book(); desktop_s += time.monotonic() - t0
        path = write_temp_book(book)
        integrity = check_integrity(open_book(path))
        if not integrity.passed:
            return result("corrupt", integrity.reason)
        v: Verdict = task.grade(path)
        return result("pass", "") if v.passed else result("wrong_state", v.reason)

    except Exception as exc:  # noqa: BLE001 - any failure here is a crash outcome
        msg = str(exc)
        return result("corrupt" if "does not balance" in msg else "crash", msg[:400])
```

```python
# cubicle/agents/_json_action.py
from __future__ import annotations
import json, re
from cubicle.harness import UnparseableResponse
from cubicle.types import Action

_FENCE = re.compile(r"```(?:json)?\s*(\{.*?\})\s*```", re.S)
_BARE = re.compile(r"\{.*\}", re.S)

def parse_action(text: str) -> Action:
    m = _FENCE.search(text) or _BARE.search(text or "")
    if not m:
        raise UnparseableResponse(f"no JSON object in response: {text[:200]!r}")
    blob = m.group(1) if m.lastindex else m.group(0)
    try:
        data = json.loads(blob)
        return Action(**data)
    except Exception as exc:
        raise UnparseableResponse(f"{exc}: {blob[:200]!r}") from exc
```

```python
# cubicle/agents/gemini.py
from __future__ import annotations
import base64, pathlib, time
from google import genai
from google.genai import types as gt
from cubicle.agents._json_action import parse_action
from cubicle.types import Action, Observation

SYSTEM = (pathlib.Path(__file__).parent / "system_prompt.txt").read_text()
MIN_INTERVAL = 6.0  # free tier is ~10 RPM; stay under it

class GeminiAgent:
    name = "gemini-2.5-flash"
    def __init__(self, api_key: str, keep_frames: int = 3):
        self.client = genai.Client(api_key=api_key)
        self.keep_frames, self.history, self._last = keep_frames, [], 0.0
    def reset(self) -> None:
        self.history = []
    def act(self, obs: Observation) -> Action:
        delta = time.monotonic() - self._last
        if delta < MIN_INTERVAL:
            time.sleep(MIN_INTERVAL - delta)
        self._last = time.monotonic()

        self.history.append(gt.Part.from_bytes(data=obs.screenshot_png, mime_type="image/png"))
        self.history = self.history[-self.keep_frames:]
        contents = [
            gt.Part.from_text(text=f"Task: {obs.task_prompt}\n"
                                   f"Step {obs.step + 1} of {obs.max_steps}."),
            *self.history,
        ]
        resp = self.client.models.generate_content(
            model="gemini-2.5-flash", contents=contents,
            config=gt.GenerateContentConfig(system_instruction=SYSTEM, temperature=0.0),
        )
        return parse_action(resp.text or "")
```

```python
"""DeepSeek V4 Flash Vision. Images are capped at 384 tokens each by the API -
a 1280x720 screenshot arrives heavily downsampled. That is a finding, not a bug."""
from __future__ import annotations
import base64, pathlib
from openai import OpenAI
from cubicle.agents._json_action import parse_action
from cubicle.types import Action, Observation

SYSTEM = (pathlib.Path(__file__).parent / "system_prompt.txt").read_text()

class DeepSeekAgent:
    name = "deepseek-v4-flash-vision-exp"
    def __init__(self, api_key: str, keep_frames: int = 3):
        self.client = OpenAI(api_key=api_key, base_url="https://api.deepseek.com")
        self.keep_frames, self.history = keep_frames, []
    def reset(self) -> None:
        self.history = []
    def act(self, obs: Observation) -> Action:
        b64 = base64.b64encode(obs.screenshot_png).decode()
        self.history.append({"type": "image_url",
                             "image_url": {"url": f"data:image/png;base64,{b64}"}})
        self.history = self.history[-self.keep_frames:]
        resp = self.client.chat.completions.create(
            model="deepseek-v4-flash-vision-exp",
            messages=[
                {"role": "system", "content": SYSTEM},
                {"role": "user", "content": [
                    {"type": "text",
                     "text": f"Task: {obs.task_prompt}\nStep {obs.step + 1} of {obs.max_steps}."},
                    *self.history,
                ]},
            ],
            temperature=0.0, max_tokens=200,
        )
        return parse_action(resp.choices[0].message.content or "")
```

```python
# scripts/run.py
"""Run the benchmark. Requires CUBICLE_SESSION_ID from scripts/setup_desktop.py -
GnuCash is installed once per desktop and every task resets in software."""
from __future__ import annotations
import argparse, dataclasses, json, os, sys, time
from pathlib import Path
from dotenv import load_dotenv
from solari_desktop import SyncDesktopClient
from cubicle.desktop import CubicleDesktop
from cubicle.harness import run_task
from cubicle.tasks import TASKS

BASE_URL = "https://api.getsolari.com"

def build_agent(name: str, cd, task):
    if name == "oracle":
        from cubicle.agents.oracle import OracleAgent
        return OracleAgent(cd, task)
    if name == "gemini":
        from cubicle.agents.gemini import GeminiAgent
        return GeminiAgent(os.environ["GEMINI_API_KEY"])
    if name == "deepseek":
        from cubicle.agents.deepseek import DeepSeekAgent
        return DeepSeekAgent(os.environ["DEEPSEEK_API_KEY"])
    raise SystemExit(f"unknown agent: {name}")

def main() -> int:
    load_dotenv()
    ap = argparse.ArgumentParser()
    ap.add_argument("--agent", required=True, choices=["oracle", "gemini", "deepseek"])
    ap.add_argument("--tasks", default="all", help="comma-separated ids, or 'all'")
    ap.add_argument("--run-id", default=time.strftime("%Y%m%d-%H%M%S"))
    args = ap.parse_args()

    ids = list(TASKS) if args.tasks == "all" else args.tasks.split(",")
    out = Path("results") / args.run_id
    out.mkdir(parents=True, exist_ok=True)

    client = SyncDesktopClient(api_key=os.environ["SOLARI_API_KEY"], base_url=BASE_URL)
    d = client.connect(os.environ["SOLARI_SESSION_ID"])
    cd = CubicleDesktop(d, os.environ["SOLARI_SNAPSHOT_ID"])

    results = []
    for tid in ids:
        task = TASKS[tid]
        agent = build_agent(args.agent, cd, task)
        print(f"[{args.agent}] {tid} ...", flush=True)
        r = run_task(cd, agent, task, trace_dir=out / "traces" / args.agent / tid)
        print(f"  -> {r.outcome} ({r.steps_used}/{r.max_steps}) {r.reason[:80]}")
        results.append(dataclasses.asdict(r))
        (out / "results.json").write_text(json.dumps(results, indent=2))

    passed = sum(1 for r in results if r["outcome"] == "pass")
    print(f"\n{args.agent}: {passed}/{len(results)}")
    return 0

if __name__ == "__main__":
    sys.exit(main())
```

```python
# cubicle/report.py
"""results.json -> a single self-contained report.html. No JS libraries, inline SVG bars."""
from __future__ import annotations
import json, sys
from pathlib import Path

def load(paths: list[Path]) -> dict[str, list[dict]]:
    return {p.parent.name if p.name == "results.json" else p.stem: json.loads(p.read_text())
            for p in paths}

def render(runs: dict[str, list[dict]]) -> str:
    rows = []
    for agent, results in runs.items():
        passed = sum(1 for r in results if r["outcome"] == "pass")
        pct = int(100 * passed / max(len(results), 1))
        rows.append((agent, passed, len(results), pct))
    rows.sort(key=lambda r: -r[3])

    bars = "\n".join(
        f'<tr><td>{a}</td><td><svg width="320" height="18">'
        f'<rect width="{int(3.2 * p)}" height="18" fill="#2f6f4f"/></svg></td>'
        f'<td>{n}/{t}</td></tr>' for a, n, t, p in rows
    )
    bars += ('<tr><td>Pinetree-CUA</td><td><svg width="320" height="18">'
             '<rect width="320" height="18" fill="none" stroke="#999" '
             'stroke-dasharray="4 4"/></svg></td><td>untested</td></tr>')

    detail = ""
    for agent, results in runs.items():
        cells = "".join(
            f'<tr><td>{r["task_id"]}</td><td>{r["outcome"]}</td>'
            f'<td>{r["steps_used"]}/{r["max_steps"]}</td><td>{r["reason"][:120]}</td></tr>'
            for r in results)
        detail += f"<h3>{agent}</h3><table>{cells}</table>"

    return (f"<!doctype html><meta charset=utf-8><title>cubicle results</title>"
            f"<style>body{{font:14px system-ui;margin:40px;max-width:900px}}"
            f"table{{border-collapse:collapse;width:100%}}td{{padding:4px 8px;"
            f"border-bottom:1px solid #eee}}</style>"
            f"<h1>cubicle</h1><p>A computer-use benchmark for software that has no API.</p>"
            f"<table>{bars}</table>{detail}")

if __name__ == "__main__":
    paths = [Path(p) for p in sys.argv[1:]]
    Path("report.html").write_text(render(load(paths)))
    print("wrote report.html")
```
